# Rust Mini Projects 🦀

A collection of command-line and utility mini-projects built while reading and practicing **[The Rust Programming Language](https://doc.rust-lang.org/book/)** ("The Book"). 

Each project in this repository is intentionally restricted to concepts introduced up to a specific chapter, demonstrating what is possible at different stages of learning Rust.

---

## 📂 Projects Directory

| Project | Description | Max Chapter |
| :--- | :--- | :--- |
| **`todo-cli`** | A terminal-based to-do list manager supporting adding, viewing, completing, and removing tasks using custom structs, enums, vectors, and robust input parsing. | **Chapter 6** |
